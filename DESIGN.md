# Native utility design

Operate mode. Follow familiar Windows controls for this narrowly specified utility.
The overlay is transparent with white tabular Consolas digits and a small dark shadow for legibility.
Settings use a light neutral surface, dark readable text, system UI fonts, 28-DIP outer spacing,
and native keyboard-operable checkboxes, slider, combo boxes and buttons.
Separate display, interaction and language groups. Keep the unlock instructions visible beside
the click-through switch. The footer says whether settings were saved. A scroll viewer accommodates
small screens and larger Windows display scaling. No decorative artwork, transitions or external fonts.
