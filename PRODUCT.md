# GameClock Overlay
<!-- impeccable:product-schema 1 -->

## Platform
Windows desktop (native WPF)

## Stack
User-selected C# / WPF / .NET 10. SDK 10.0.403, installed Windows Desktop Runtime 10.0.14. No external NuGet dependencies, UWP, or WinUI.

## Users and purpose
Personal use and a small circle of friends. Read local time while gaming or using the desktop.

## Capabilities and constraints
User-confirmed: HH:mm, optional seconds, opacity, dragging and four corners, click through with recovery, tray, persistent settings, Traditional Chinese / English / Japanese with system default and manual priority, MIT. No injection, game hooks, elevation, or network. GitHub source publishing is explicitly authorized for this preparation. User tested borderless fullscreen successfully; exclusive fullscreen is unsupported. Supported validation platform: Windows 11 x64.

## Product principles
Lightweight implementation, safe recovery, maintainable source, proportional verification.
